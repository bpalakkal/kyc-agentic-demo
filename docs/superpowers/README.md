# Archived design records

The plans and specifications in this directory are historical implementation records. Some predate the no-Forge architecture and therefore mention Forge branding, an AWS agent runtime, the former `/kyc-agentic2/` path, mock data, or features that have since changed.

Do not use these files as current operating instructions. Current sources of truth are:

- `/README.md` for setup and architecture
- `/PRODUCTION_NOTES.md` for deployment and operations
- `/agents.md` for implementation conventions
- `/schema/kyc_master_attribute_schema.json` for the attribute contract
